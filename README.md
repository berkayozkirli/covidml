# covidml

An ML project predicting whether a country's COVID-19 cases will increase
by at least 25% over the next two weeks, using epidemiological data and government measures. The analysis compares a persistence baseline, logistic regression, XGBoost, and a causal temporal convolutional network (TCN).

## Project layout

```text
src/covidml/
    models/
        baseline.py       # Persistence predictions
        linear.py         # Logistic regression constructor
        boosting.py       # XGBoost classifier and pipeline constructors

```

## Setup

Requires Python 3.13 or later. From the project root:

```sh
uv sync
uv run python -m ipykernel install --user --name covidml --display-name "Python (covidml)"
```

Open `notebooks/project_notebook.ipynb` in your notebook editor and select the
`Python (covidml)` kernel (or select `.venv/bin/python` directly). `uv sync`
installs `covidml` as an editable package, so changes under `src/` are available
without reinstalling; restart the kernel after editing already imported modules.

For pip-based environments, install with `python -m pip install -e .` and select
that environment as the notebook kernel instead.

The notebook runs with the working directory set to either the project root or
`notebooks/`. It locates `datasets/` and writes to the root `figures/` directory
without modifying `sys.path` or changing the working directory.

The following input files are expected in `datasets/`:

- `acaps_covid19_government_measures_dataset.xlsx` (the `Dataset` sheet)
- `owid-covid-data.csv`

Run the notebook in order. Model comparisons use the validation split; the final
test report reuses the model with the highest validation F1, the existing test
split, and the fitted normalizer. It does not repeat preprocessing or tuning.
The separate XGBoost ablation keeps the chosen hyperparameters fixed and trains
one additional model without the engineered policy features.

Earlier sections retain their original saved outputs for reference. Outputs for
the revised test report, error analysis, and ablation are cleared until rerun.
Full TCN and XGBoost hyperparameter searches can take substantial time.

## Use the package

```python
from covidml.evaluation import ModelResults
from covidml.models import (
    make_logistic_regression,
    make_xgboost_classifier,
    make_xgboost_pipeline,
    persistence_predictions,
)
from covidml.preprocessing import (
    CovidDataPreprocessor,
    TargetGenerator,
    TimeSeriesImputer,
)

model = make_logistic_regression(C=1.0)
model.fit(X_train, y_train)
predictions = model.predict(X_val)
```

Model constructors preserve the notebook's defaults and accept keyword overrides.
The TCN is a plain PyTorch module. Dataset construction, batching, training, and
inference are separate:

```python
import torch

from covidml.data import COVIDSequenceDataset, make_sequence_loader
from covidml.models import TCN
from covidml.training import predict_tcn, train_tcn

train_data = COVIDSequenceDataset(X_train_norm, train_df, temporal_cols, static_cols)
val_data = COVIDSequenceDataset(X_val_norm, val_df, temporal_cols, static_cols)
train_loader = make_sequence_loader(train_data, batch_size=8, shuffle=True)
val_loader = make_sequence_loader(val_data, batch_size=8)

torch.manual_seed(42)
model = TCN(
    temp_channels=len(temporal_cols),
    static_channels=len(static_cols),
    hidden_channels=64,
    num_layers=3,
)
losses = train_tcn(model, train_loader, epochs=30, learning_rate=0.001)
surge_probabilities = predict_tcn(model, val_loader)
predictions = (surge_probabilities >= 0.5).astype(int)
```

Normalized features and raw frames must contain corresponding rows in the same
order; their index labels can differ. Rows should be ordered by time within each
country, as they are in the notebook. Training excludes padded timesteps from the
loss. Predictions contain one surge probability per original input row, restored
to input order even when countries are shuffled between batches. Training returns
loss history separately from the model. `TCNClassifier` has been removed.
